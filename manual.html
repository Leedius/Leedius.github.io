사용 설명서

Create Pack 을 할 일 순서로 풀었어요. 처음이면 1장부터 읽고, 찾는 것이 있으면 차례에서 바로 가요.

그림의 보라 네모칸 번호는 그림 아래 풀이와 짝이에요. 풀이에 마우스를 올리면 그 자리가 밝아져요. 화면 속 게임과 그림은 설명하려고 지어낸 예시예요.

1

시작하기

내려받고 켜기

  • 소개 페이지의 「Windows 용 내려받기」 를 누르면 CreatePack.exe 하나가 받아져요. 설치 없이 바로 켜져요.
  • 서명하지 않은 파일이라 Windows 가 「PC 보호」 창을 띄우면 「추가 정보 → 실행」 을 눌러요.
  • exe 옆에 둘 파일은 없어요. 계정과 키는 켠 뒤 오른쪽 위 톱니바퀴 「설정」 에서 넣어요(6장).
  • 새 판이 나오면 켤 때 물어요. 「확인」 을 누르면 받아서 스스로 갈아끼워요.
  • 앱은 한 번에 하나만 떠요. 켜져 있는데 exe 를 또 누르면 새 창 대신 먼저 켠 창이 앞으로 와요.

팩이란

팩은 library.json 이 든 폴더 하나예요. 담은 롬 · 그림 · 제목이 모두 이 안에 모여요.

MyPack/ ├ library.json 팩 목록 — 제목 · 설명 · 그림 자리 ├ roms/<기종>/ 롬 파일 ├ media/ 그림 · 영상 ├ _trash/ 팩 휴지통 — 지운 게임 · 바꾼 그림 └ devices/ 기기 설정 저장본

처음 켜면 「팩 열기…」 · 「새 팩 만들기…」 카드가 떠요. 새 팩은 빈 폴더를 고르면 거기에 만들어요.

화면 한눈에

머리줄의 단추는 이래요.

  • 「팩 ▾」 의 「롬 폴더 모두 다시 읽기」 는 roms/ 를 훑어 새 롬은 더하고 없어진 롬은 빼요. 「목록 파일 다시 읽기」 는 목록 파일(library.json)만 다시 읽어 복사가 도는 동안 늘어난 것을 화면에 반영해요.
  • 「기기 ▾」 에는 기기로 가는 길 셋이 줄마다 풀이와 함께 있어요 — 「내보내기…」(머리줄의 파란 단추와 같은 창) · 「외부 기기 팩 열기…」 · 「기기 설정…」.
  • 머리줄의 「게임 N · 제목 % · 표지 %」 는 제목과 표지를 가진 게임이 얼마나 되는지 보여 줘요.
  • 구분선(선반 아래 · 서랍 위 · 서랍 안 칸 사이)은 끌어서 크기를 바꾸고, 두 번 누르면 원래대로 돌아가요.
2

게임 담기

롬 폴더를 기종째 담거나, 담아 둔 기종에 몇 개씩 넣어요. 팩 밖의 원본은 건드리지 않고 복사해 와요.

기종째 담기

선반 왼쪽 위 「+ 기종…」 을 눌러요.

  • 롬 폴더를 비워 두면 팩 안에 빈 roms/<종류>/ 를 만들어요. 나중에 「+ 게임…」 으로 채워요.
  • 고른 폴더에 gamelist.xml 이나 metadata.pegasus.txt 가 있으면 항목 체크(제목 · 설명 · 장르 · 그림 · 영상 …)가 떠요. 체크한 항목은 그 파일의 값으로 채워요.
  • 안드로이드(USB) · 커스텀 리눅스(SFTP) 기기에서 가져오면 먼저 PC 로 복사한 뒤 담아요.

몇 개만 넣기

기종을 고른 채 목록 머리의 「+ 게임…」 을 눌러요.

무엇이 몇 개, 얼마만큼 갈지 먼저 보여 주고, 「넣기」 를 누르면 따로 뜬 진행 창에서 복사해요. 못 찾은 딸린 파일(cue 가 가리키는 bin 등)이 있으면 경고해요. 진행 창이 뜬 작업이 끝났을 때 다른 프로그램을 보고 있으면 작업 표시줄의 앱 단추가 깜빡여 알려 줘요.

폴더 다시 읽기

탐색기에서 롬 폴더를 직접 고쳤으면 앱에 다시 읽혀요. 선반의 기종 카드에 마우스를 올리면 나오는 ↻ 를 누르거나, 「⋯」 메뉴의 「여러 기종 롬 폴더 다시 읽기」 로 여럿을 한꺼번에 해요.

알아 둘 것「없어진 롬만 빼기」 · 「롬 폴더 모두 다시 읽기」 는 롬 파일이 없어진 게임을 목록에서 빼지만, 적어 둔 제목 · 설명 · 그림 정보는 팩에 챙겨 둬요. 같은 롬을 같은 자리에 다시 넣고 다시 읽으면 되살아나요.

목록 다루기

  • 표 보기에서는 열 머리를 눌러 정렬해요. 표지 보기에서는 표지 위 「한글」 띠가 파일 이름에 (k) 가 든 한글패치판이에요.
  • 검색은 기종을 안 골라도 검색어가 있으면 모든 기종에서 찾아요.
  • 게임을 체크하면 목록 아래에 선택 줄이 나와요.
    • 「선택 압축」: 기종에 맞는 꼴(rvz · chd · zip)로 압축해요. 옛 파일은 팩 휴지통으로 가요.
    • 「휴지통으로」(Delete 키): 고른 게임을 팩 휴지통으로 옮겨요. 외부 기기 팩을 연 동안에는 기기에 휴지통이 없어 이 단추가 「영구 삭제」 로 바뀌어요.
    • 「선택 합치기」: 여러 장 디스크를 m3u 한 줄로 합쳐요. 되돌리는 기능이 없어요.
  • 기종을 목록에서 빼려면 선반 카드에 마우스를 올려 ✕ 를 눌러요. 롬 파일은 그대로예요. 「롬 폴더 모두 다시 읽기」 를 해도 뺀 기종은 돌아오지 않고, 「+ 기종…」 으로 같은 폴더를 다시 담으면 적어 둔 제목 · 설명이 같이 돌아와요.

휴지통

지운 게임은 팩 안 _trash/ 로 가요. 머리줄 「휴지통 (N)」 은 지운 게임이 있을 때만 보여요.

되돌리면 롬 · 그림 · 제목 · 설명이 함께 돌아와요. 같은 이름의 롬이 팩에 이미 있으면 그 게임은 되돌리지 않아요.

3

제목·그림 채우기

한 게임씩 고르고 고치거나, 기종째 한꺼번에 찾아 넣어요. 인터넷 자료는 ScreenScraper(무료 계정)와 libretro(계정 없음)에서 찾아요.

먼저screenscraper.fr 에서 무료 계정을 만들어 「설정 › ScreenScraper」 에 넣고 「계정 확인」 을 눌러 두면 찾는 것이 훨씬 많아요. AI 기능은 설정의 AI 탭에 본인 키를 넣어야 돌아요.

상세 서랍

목록에서 게임을 하나 누르면 아래 서랍에 떠요.

  • 그림 칸 아홉(표지 · 스크린샷 · 타이틀 · 로고 · 3D 박스 · 옆면 · 박스 전개 · 카트리지 · 디스크 · 영상)은 늘 같은 자리에 있어요. 칸 왼쪽 아래에 그림의 지역이 적혀요.
  • 칸을 고르고 「그림 편집…」(영상 칸이면 「영상 편집…」)으로 손봐요. 서랍에서 바꾼 그림 · 영상은 바로 팩에 저장돼요.

한 게임씩 고치기 — 메타 편집

서랍의 「메타 편집…」 을 눌러요.

  1. 찾기검색 칸에 게임 이름을 넣고 Enter 를 누르면 ScreenScraper 에서 찾아요. 비워 두면 롬 파일 이름으로 찾아요. 「libretro 썸네일」 은 계정 없이 그림만 가져와요.
  2. 찾은 게임 고르기찾은 게임은 왼쪽 목록에 떠요. 하나를 누르면 그 게임의 값이 「찾은 것」 으로 들어가요. 롬 파일 이름으로 찾아 하나만 나오면 저절로 골라요.
  3. 쓸 쪽 고르기칸마다 「적용」 때 들어갈 값 하나만 보여요. 줄 끝 「팩」 은 지금 팩 값을, 「찾은 것」 은 찾은 값을 써요. 「적용」 하면 바뀌는 칸은 왼쪽에 빨간 띠가 있어요. 찾기 줄 끝이 「빈 칸만」 이면 팩에 값이 있는 칸은 「팩」 으로, 「다 바꾸기」 면 모든 칸을 「찾은 것」 으로 처음 맞춰요.
  4. 다듬기칸에 보이는 값을 고쳐 쓰면 그 쪽 값이 바뀌어요. 「AI로 빈 칸 채우기」 는 한글 제목 · 영어 제목 · 장르 · 출시일 · 개발사 · 인원 중 빈 칸을, 설명 줄 「번역」 은 설명을 한국어로 옮겨요.
  5. 적용「적용」 을 눌러야 칸에 보이는 글과 「찾은 것」 으로 둔 그림이 저장돼요. 적용하지 않고 닫으면 저장할지 물어요.
  • 그림 칸 머리의 「9칸」 · 「크게」 로 보기를 바꿔요(Enter 로도). 「크게」 는 위 탭으로 종류를 넘기고, 영상은 그 자리에서 틀어요. 누른 보기는 다음 게임에도 그대로예요.
  • 찾은 그림에 지역판이 여럿이면 9칸에서는 그림 귀의 「jp · 3판 ▾」 를, 크게에서는 판 단추(jp · us …)를 눌러 바꿔요. 바꿔도 쓸 쪽은 그대로예요.
  • 「찾은 그림 모두 쓰기」 는 찾은 게임의 그림 · 영상을 모두 「찾은 것」 으로 둬요(지역판은 한국 · 세계 · 미국 · 유럽 · 일본 차례의 첫 판). 글 칸은 그대로예요.
  • 그림 칸의 「파일 없음」 은 목록에는 있는데 팩에 파일이 없다는 뜻이에요.
  • 단축키 — ↑ ↓ 줄 고르기 · Enter 9칸 ↔ 크게 · S 쓸 쪽 · F 편집 · D 빼기(두 번) · A 모두 쓰기 · ← → 지역판. 아래 줄의 ⌨ 를 누르면 키를 바꿔요.
  • 찾은 제목을 우리 표기로 맞추지 못하면 「제목 표기 확인」 창이 떠서 「AI 추천」 · 「원래대로 두기」 · 「이대로 쓰기」 중에 골라요.
  • 머리의 「이름 바꾸기」 는 롬 파일 이름을 바꾸고 그림 이름도 따라 바꿔요. 「파일 교체…」 는 롬을 다른 파일(예: 한글패치본)로 갈아끼워요. 제목 · 설명은 그대로고, 옛 롬은 팩 휴지통으로 가요.
조심이 창에서 저장 시점이 둘이에요. 「편집…」 으로 손본 그림 · 「파일로…」 로 바꾼 영상 · ✕ 빼기는 바로 저장되고, 글 칸 · 「찾은 것」 으로 둔 그림 · 「영상 편집…」 은 「적용」 때 저장돼요.

그림 손보기 — 그림 편집

서랍이나 메타 편집 창에서 그림 칸을 고르고 「그림 편집…」 · 「편집…」 을 눌러요.

  • 창을 열면 구글 이미지에서 바로 찾아 둬요. 칸에 그림이 있으면 「손보기」 로, 없으면 「그림 찾기」 로 열려요. 로고 칸은 투명 배경 그림만 찾아요.
  • 「그림 찾기」 는 찾은 그림을 크게 늘어놓아요. 누르면 받아서 「손보기」 로 넘어가요(원본을 못 받으면 구글의 작은 그림). 그림 주소 · PC 파일로도 열고, 오른쪽 「이 그림 손보기」 는 팩의 지금 그림을 다시 열어요.
  • 「손보기」 왼쪽에도 찾은 그림이 한 줄로 있어, 보기를 바꾸지 않고 그림을 바꿔요.
  • 한글 제목이 있는 게임은 찾기 칸 옆 단추로 한글 제목 · 영어 제목을 바꿔 찾아요.
  • 도구 판의 「모양」 에는 「잘라 내기」 · 「크기 바꾸기」(가로 · 세로 픽셀 수)가 있어요. 켠 도구의 설정과 실행 단추는 도구 판 맨 아래에 펼쳐지고, 쓰는 법은 창 아래 줄에 떠요.
  • 「배경」 의 「바깥 배경」 은 그림 네 귀에 닿은 배경만 지우고, 「눌러서 지우기」 는 누른 색이나 끈 사각형 안을 지워요. 「색 차이」 를 키우면 조금 다른 색까지 배경으로 봐요.
  • 「펴기」 의 「알아서 펴기」 는 비스듬히 찍은 박스 사진을 반듯하게 펴요. 「네 귀 찍어」 로 점 넷을 직접 옮길 수도 있어요.
  • 박스 전개 칸에서는 「앞표지 · 옆면으로 짜기」 로 [뒷표지(초록) · 옆면 · 앞표지] 전개도를 바로 만들어요. 옆면 그림이 없으면 「옆면」 칸에 먼저 넣어요.
  • 「AI 누끼…」 는 그림 AI 에게 배경을 지워 달라고 보내요. 1~2분 걸리고 본인 키로 요금이 나가요. 쓸 서비스와 모델은 「설정 › AI 미디어 한글화 · 편집」 에서 골라요. 결과는 「되돌리기」 로 무를 수 있어요.
조심「팩에 저장」 은 PNG 로 같은 자리의 그림을 덮어써요. 옛 그림은 팩 휴지통으로 가지 않아요.

ScreenScraper · libretro 로 채우기

선반에서 기종을 하나 고르고 목록 머리 「채우기 ▾ › ScreenScraper · libretro 로 채우기…」 를 눌러요. 「전체」 를 보는 동안에는 잠겨 있어요.

  1. 찾을 칸 고르기채우고 싶은 그림 · 글 칸만 체크해요. 고른 칸이 하나라도 빈 게임만 목록에 들어요. 영상은 파일이 커서 오래 걸려요.
  2. 있는 그림「빈 칸만 채우기」 는 이미 넣은 그림(한글화한 표지 등)을 그대로 둬요. 「전체 교체」 는 고른 그림 칸을 모두 새로 받고, 옛 그림은 팩 휴지통으로 보내요. 글은 어느 쪽이든 빈 칸만 채워요.
  3. 찾기찾을 곳(ScreenScraper · libretro)을 고르고 「찾기」 를 눌러요. 진행 창에서 몇 개째인지 보이고 「멈추기」 로 멈출 수 있어요.
  4. 보고 체크하기표의 「찾은 곳」 에 무엇으로 맞췄는지 적혀요. 확실한 것은 미리 체크돼 있어요. 나머지는 표지와 이름을 보고 직접 체크해요.
  5. 적용「선택한 것 적용」 을 누르면 체크한 줄만 받아 넣어요.
스크래핑이 무엇으로 맞추나요
찾는 순서
ScreenScraper 에 롬(내용 CRC · 크기 · 파일 이름)으로 먼저 묻고, 채울 것을 못 찾으면 게임의 영어 제목으로 검색해요. libretro 는 롬 파일 이름 → 영어 제목 순으로 표지 · 타이틀 · 스크린샷만 찾아요.
미리 체크
「롬 해시가 같음」 · 「파일 이름 그대로」 로 맞춘 줄만 미리 체크돼요. 「서버가 이름으로 맞춤」 과 영어 제목 검색으로 찾은 줄은 옆 게임(1편↔2편, 일본판↔한국판)일 수 있어 직접 봐요. 한글패치한 롬은 해시가 달라서 보통 이쪽으로 와요.
제목이 같으면
「제목이 같으면 미리 체크」 를 켜면 찾은 이름이 지금 제목과 글자 그대로 같은 줄도 미리 체크해요. 기본은 꺼져 있어요.
영어 제목
롬으로 못 찾은 게임은 영어 제목이 없으면 ScreenScraper 검색을 건너뛰어요. 「AI로 빈 칸 채우기」 나 메타 편집에서 영어 제목을 먼저 채워 두면 더 많이 찾아요.
설명 언어
한국어 설명이 없으면 영어로 와요. 메타 편집의 「설명 번역」 으로 옮겨요.
하루 조회 수
ScreenScraper 는 계정마다 하루에 물을 수 있는 수가 정해져 있고, 게임마다 한두 번 물어요. 남은 수는 「설정 › ScreenScraper」 의 「계정 확인」 으로 봐요.

AI로 빈 칸 채우기

「채우기 ▾ › AI로 빈 칸 채우기…」 는 고른 기종 게임들의 빈 칸을 AI 에게 한꺼번에 물어요.

  • 답은 빈 칸 자리에 밝게 뜨고, 이미 있는 값은 흐린 글자로 그대로 둬요. 새 값을 받은 줄은 저절로 체크돼요.
  • 중간에 끊겨도 받은 것까지는 남아요. 다시 누르면 남은 게임만 물어요.
  • 쓸 AI(Gemini · ChatGPT · Claude)는 「설정 › AI 글 채우기 · 번역」 에서 골라요. 요금은 본인 키로 그 서비스에 나가요.

그림 속 글자 한글화

메타 편집 창 아래 띠의 「AI 미디어 한글화…」 는 표지 · 로고 · 타이틀 같은 그림 속 글자를 한글 제목으로 다시 그려요. 왼쪽 목록 한 줄이 그림 종류 하나예요.

  1. 보낼 내용오른쪽 칸에 그림에 넣을 한글 제목을 적고, 필요하면 「추가 지시」 를 더해요. 제공자 · 모델 · 품질도 여기서 골라요.
  2. 그림 고르기왼쪽 목록에서 바꿀 종류를 체크하고 확인 체크를 켠 뒤 「한꺼번에 그리기」 를 눌러요. 로고를 먼저 그리고, 표지는 로고를, 나머지는 로고나 표지를 본보기로 같이 보내요.
  3. 글 지도표지 · 3D 박스 · 박스 전개는 그리기 전에 글 AI 가 그림 속 글을 칸마다 읽어 가운데 아래 「글 지도」 표에 원문 → 한국어로 보여요. 그리기는 멈추지 않아요. 고칠 글이 있으면 한국어 칸을 고치거나 「바꿈」 을 끈 뒤 「다시 그리기」 를 눌러요. 표에 없거나 「바꿈」 을 끈 글은 원본 그대로 남아요. 그리기 전에 보고 싶으면 「글만 먼저 읽기」 를 눌러요.
  4. 견주기목록에서 종류를 고르면 가운데에 원본과 한글화 결과가 같은 크기로 크게 나란히 떠요. 휠로 키우면 두 칸이 같이 커지고 같이 굴러가요. 그 종류만 다시 그리려면 「다시 그리기」, 실패한 것을 모두 다시 그리려면 「실패만 다시」 를 눌러요.
  5. 적용그린 종류는 쓸 쪽이 「한글화 결과 ▶」 로 바뀌어요. 원본을 남길 종류는 「◀ 원본 그대로」 로 돌리고 「고른 것 적용…」 을 누르면 결과 쪽 종류만 원본 자리에 갈아끼워요.
  • 목록에 초점이 있으면 ↑ ↓ 종류 옮기기 · Space 쓸 쪽 · Del 빼 두기 키가 먹어요.
조심그림마다 따로 요청을 보내 요금이 나가요(구독과 별도). 취소해도 이미 보낸 요청은 청구될 수 있어요. 적용하면 원본 그림 자리에 갈아끼우고 옛 그림 파일은 팩 휴지통(_trash/)으로 옮겨요(외부 기기 팩에서는 지워요).

영상 넣기

서랍이나 메타 편집 창의 영상 칸에서 「영상 편집…」 을 눌러요.

  • 창을 열면 게임 제목으로 유튜브를 바로 찾아 「영상 고르기」 에 보여요(끝까지 내리면 더 찾아요). 고르면 「받을 화질」(처음은 720p)로 받아 와서 「장면 자르기」 로 넘어가 틀어요. 맨 위 오른쪽 칸에 영상 주소를 적거나 「PC 에서 고르기…」 로 내 파일(mp4 · mkv · webm · mov)을 열어도 돼요. 한글 제목이 있으면 찾기 칸 옆 단추로 한글 · 영어 제목을 바꿔 찾아요.
  • 영상 밑 띠의 괄호 둘([ ])을 끌거나, 원하는 장면에서 「[ 여기부터」 · 「여기까지 ]」 를 눌러 넣을 장면을 골라요. 시각 칸에 1:05.3 처럼 적어도 돼요. 빨간 선이 지금 트는 자리고, 띠를 누르면 그 자리로 가요. 「고른 장면 보기」 로 괄호 사이만 틀어 보고, 「고른 장면 넣기」 로 그 장면만, 「통째로 넣기」 로 영상 전체를 넣어요.
  • 「장면 자르기」 에서는 키보드로도 돼요 — Space 재생 · I 여기부터 · O 여기까지 · ← → 1초(Shift 를 같이 누르면 0.1초) · P 고른 장면 보기.
  • 처음 쓸 때 영상 도구(yt-dlp · ffmpeg)를 한 번 받아요.
  • 서랍에서 열었으면 바로 저장되고, 메타 편집 창에서 열었으면 그 창의 「적용」 때 저장돼요.

사용자 그림 — 다른 사람이 올린 그림 쓰기

다른 사람이 고쳐 올린 표지 · 로고 같은 그림을 내 팩에 쓰고, 내가 손본 그림을 올려 나눠요. 보기 · 고르기 · 「적용」 은 로그인 없이 되고, ♥ 와 올리기는 「설정 › 계정」 에서 로그인하고 별명을 정한 뒤에 할 수 있어요.

  • 메타 편집 창에서 그림을 「크게」 로 보면 오른쪽에 「사용자 〈종류〉」 칸이 떠요. 그림을 누르면 그 그림을 쓰고, 「적용」 을 눌러야 팩에 들어가요. 정렬(최신 · 좋아요 · 적용)과 ‹ › 로 더 봐요. 「찾기」 는 다른 게임에 올라온 그림도 골라 쓰게 해 줘요.
  • 칸 맨 앞 「올리기」 는 지금 팩에 저장된 그 종류의 그림을 올려요. 자동 검사를 통과하면 바로 모두에게 보이고, 애매하면 관리자가 보고 공개해요. 게임 · 종류마다 2장, 하루 500장, 한 장 4MB(PNG · JPEG · WebP)까지예요. 영상은 올릴 수 없어요.
  • 내가 올린 것은 칸 앞쪽에 「내 것」 으로 보여요. 눌러서 상태를 보거나 지우고, 모두 보려면 「설정 › 계정」 의 「내가 올린 것」 으로 가요.
  • 큰 그림 위 ⋯ 로 남의 그림을 신고해요. 남의 권리를 침해한 그림은 내려지고, 내려진 그림이 5번이 되면 올리기가 잠겨요.
  • 머리줄 「사용자 그림」 을 누르면 모든 게임의 순위 · 인기 그림 · 새로 올라온 것을 봐요. 순위 판은 오늘 · 이번 주 · 이번 달 ♥ 와 누적 적용 넷이고, ‹ › 로 지난 판도 봐요. 별명을 누르면 그 사람이 올린 그림이 오른쪽에 떠요.
  • 「인기 그림」 은 기간 · 기종 · 종류 · 「내 팩에 있는 게임만」 으로 걸러요. 그림 아래 「내 팩에서 열기」 는 그 게임의 메타 편집 창을 이 그림을 고른 채로 열어요.
  • 이 기능이 꺼져 있거나 서버에 닿지 못하면 머리줄 단추와 메타 편집 창의 칸이 보이지 않아요.
4

한글패치

레트로디비(retrodb.info) 한글패치 목록을 보고, 배포처에서 직접 받은 패치를 원본 롬에 걸어 한글판을 만들어요. 앱이 패치를 대신 받아 주지는 않아요 — 받는 것은 브라우저고, 앱은 받은 파일을 정리하고 걸어요.

한글패치 창

머리줄 「한글패치」 를 눌러요. 팩을 안 열어도 돼요. 받은 파일은 KRPATCH/기종/게임/ 에 모아요.

  • 목록에서 줄을 누르면 오른쪽 칸에 그 게임의 ① 받기 · ② 패치 적용 · ③ 게임 폴더가 한꺼번에 떠요.
  • 「보유」 칸은 받아 둔 폴더와 기록으로 정해요 — 원 원본 롬 · 패 받은 패치 · 본 패치한 롬. 날짜는 오른쪽 칸 머리에 보여요.
  • 목록 머리 오른쪽 「목록 새로 받기」 는 사이트에서 새로 오른 패치를 받아 더해요. 키는 앱에 들어 있어 따로 신청하지 않아도 돼요. 받은 목록은 1시간 동안 다시 묻지 않아요.
  • 맨 아래 「자리…」 에서 받을 곳 · 받아 둔 곳 · 목록 · 기록 파일 자리를 바꿔요. 자료 폴더를 나스에 두면 다른 컴퓨터와 같이 써요.

받기

  1. 감시 폴더 정하기① 받기의 「감시 폴더」 를 「바꾸기…」 로 브라우저가 파일을 내려받는 폴더에 맞춰요(처음 한 번).
  2. 「받기 감시 켜기」목록에서 받을 게임을 고르고 ① 받기의 「받기 감시 켜기」 를 눌러요. 게임 폴더와 그 안 원본/ 을 만들고 받기 감시를 켜요. 한 번에 한 게임만 켜지고, 단추는 「감시 끄기」 로 바뀌어요. 다른 게임을 보는 동안에는 목록 위 띠에 감시 중인 게임이 보여요. 처음 켤 때는 받은 게임 폴더를 둘 「받을 곳」 을 한 번 물어요.
  3. 배포처에서 받기「배포처 ↗」 를 눌러 브라우저에서 패치(필요하면 원본 롬도)를 받아요.
  4. 어디에 넣을지 고르기파일이 다 받아질 때마다 「원본에 넣기」 · 「게임 폴더에 넣기」 · 「옮기지 않기」 를 물어요. 앱이 짐작한 쪽이 기본 단추예요.
  5. 패치 적용으로원본과 패치가 다 모이면 그 게임의 ② 패치 적용 칸이 저절로 채워져요(다른 게임을 보고 있으면 그대로 둬요). 「감시 끄기」 는 받기 감시만 꺼요.
받은 파일마다 묻는 창
원본에 넣기
게임 폴더 안 원본/ 으로 옮겨요. zip · 7z 는 풀어 넣고(맨 위 폴더 하나는 벗겨요) 압축 파일은 지워요(휴지통 아님). 같은 이름이 이미 있으면 덮지 않고 압축째 남겨 두고, 까닭을 ① 받기의 받은 파일 표에 붙여요.
게임 폴더에 넣기
게임 폴더로 옮겨요. 패치 파일이 보통 여기로 가요. 같은 이름이 있으면 덮어요.
옮기지 않기
받은 폴더에 그대로 둬요. 받은 파일 표에도 안 남아요.
묻지 않기
「이번 받기 동안 … 묻지 않고 여기에 넣기」 를 켜면 같은 종류(패치로 보이는 것 · 원본으로 보이는 것)는 그 뒤로 묻지 않고 같은 곳에 넣어요.
나눈 압축
여러 조각으로 나눈 압축은 조각이 다 와야 한 번 물어요.

괄호 ( ) · [ ] 안은 이름을 맞출 때 빼니 메모를 적어도 돼요. (0823) 처럼 월일 네 자리로 시작하면 받은 날로 읽고, 그때 나와 있던 판을 「보유」 에 적어요.
결과
패치한 롬은 게임 폴더에 <원본 이름> (k)[배포일].<확장자> 로 생겨요. 배포일이 이름에 들어 있어서 다른 폴더로 옮긴 뒤에도 어느 판인지 알 수 있어요.
보유 칸
「받을 곳」 을 「받아 둔 곳」 과 다른 폴더로 두면 받기만 한 게임은 창을 다시 열 때 「보유」 에서 빠져요. 둘을 같은 폴더로 두면 편해요. 탐색기에서 폴더를 바꿨으면 목록 머리 ⋯ 메뉴의 「다시 읽기」 를 눌러요.

패치 걸기

폴더가 있는 게임을 목록에서 고르면 오른쪽 ② 패치 적용 칸에 그 게임의 원본 · 패치가 채워져요.

  • 앱이 고른 원본 · 패치에는 「자동」 배지가 붙어요. 「찾아보기…」 로 바꿀 수 있고, zip · 7z 를 고르면 안의 롬을 풀어 걸어요.
  • 「해시」 는 원본이 패치가 바라는 롬인지 보여 줘요 — ✓ 맞아요 · ✗ 틀려요 · ? 미심쩍어요 · – 볼 것이 없어요. 패치 안의 값과 같이 받은 설명 글(checksums.txt · readme 등)의 해시로 견줘요. 해시 값은 「해시 보기」 로 봐요.
  • xdelta · bps · ips · ups 를 걸어요. CD 이미지가 오류 정정 값만 달라 안 걸리면 그 값을 다시 계산한 사본에 한 번 더 걸어요.
  • 앱 밖에서 직접 패치했으면 「적용 기록」 으로 「보유」 칸에 적어 둬요.
조심

원본은 손대지 않고 복사본에 걸어요. 다 걸면 걸었던 패치 파일을 PC 휴지통으로 보낼지 물어요(기본은 남기기 · dlc 가 든 것 등은 남겨요). 받을 곳이 나스면 휴지통이 없어 영구 삭제할지 한 번 더 물어요.

「적용한 뒤 압축」 을 켜면 압축 전 결과 파일은 휴지통으로 가요. 받을 곳이 나스면 휴지통이 없어 영구 삭제예요.

그 밖에

  • 목록 머리 ⋯ 메뉴의 「목록에 직접 더하기…」: 목록에 없는 패치를 직접 더해요. 「목록 새로 받기」 를 해도 남아요. 오른쪽 칸 머리 ⋯ 메뉴의 「판 더하기…」 · 「줄 고치기…」 로 줄을 손봐요. 목록 제목 뒤 「메」 를 누르면 게임 메모를 써요 — 메모가 있으면 색이 켜지고, 마우스를 올리면 메모가 보여요.
  • ⋯ 메뉴의 「폴더 점검…」: 아무 롬 폴더나 골라 이름 끝의 (k)[배포일] 로 가진 판이 최신인지 봐요.
  • ⋯ 메뉴의 「팩에 넣기…」: 받아 둔 한글 롬 가운데 팩에 없는 것만 팩 기종 폴더로 복사해요. 팩 파일은 덮지도 지우지도 않아요. 넣은 뒤 「팩 ▾ › 롬 폴더 모두 다시 읽기」 를 해야 팩 목록에 보여요.
  • 줄 제목 앞 재생 단추: 그 게임을 유튜브에서 찾아 앱 안에서 틀어 봐요. 굴려서 맨 아래까지 가면 더 받아요.
  • ③ 게임 폴더 표에서 파일 이름을 바꾸거나(「이름」) PC 휴지통으로 보내요(「휴지통」).
  • 디스크 기종은 ② 패치 적용의 「기종 도구 ▾」 에 「디스크 풀기」 · 「m3u 로 묶기」 · 「롬 압축…」 같은 도구가 나와요.
5

기기로 보내기

팩을 RetroBat · Batocera · ROCKNIX · Pegasus · ES-DE 가 읽는 모양으로 내보내요. 머리줄 「내보내기…」(또는 「기기 ▾ › 내보내기…」)를 눌러요.

내보내기

팩 안에 메타만
팩 roms/<기종>/ 에 목록 파일만 만들어요. 몇 초면 끝나요. 있던 목록 파일은 덮어써요.
롬·그림 복사
롬 · 그림까지 폴더 · 커스텀 리눅스(SFTP) · 안드로이드(USB)로 보내요(아래).
기기 메타에 보태기
기기에 이미 있는 목록에 팩 정보를 보태요 — 빈 설명 · 장르 따위만 채우고, 목록에 없는 게임은 끝에 붙여요(아래).

프론트엔드는 셋이에요. RetroBat · Batocera · ROCKNIX 는 gamelist.xml, Pegasus 는 metadata.pegasus.txt 를 만들어요. ES-DE 는 메타 · 그림을 ES-DE/ 아래로, 롬을 ROMs/ 로 보내고 폴더 이름을 ES-DE 이름으로 바꿔요(예: 3ds → n3ds).

롬·그림 복사

  • 이름 · 크기가 같은 파일은 건너뛰어요. 멈췄다가 다시 눌러도 이어서 가요. 내용만 바뀐 롬도 보내려면 「크기가 같아도 다시 보내기」 를 켜요. 켜도 기기의 세이브와 「목적지 것 두기」 로 지킨 그림은 덮지 않아요.
  • 「그림이 겹치면」: 「팩 것으로 덮기」 는 크기가 다른 그림만 팩 것으로 바꾸고(크기가 같으면 같은 그림으로 보고 건너뛰어요), 「목적지 것 두기」 는 목적지 그림을 그대로 둬요. 롬에는 안 걸려요.
  • 「게임 표에서 체크한 게임만」 을 켜면 목록에서 체크한 게임만 보내요(게임 목록은 늘 「병합」).
  • 「제목」 은 한글 우선 또는 영어 제목 우선으로 골라요.
  • Pegasus 의 실행 명령(launch)은 안드로이드 RetroArch 기준이에요. PC 용 Pegasus 로 보낼 때는 「고급」 에서 꺼요.
조심기기에 이미 실행 명령(launch)이 적힌 목록이 있으면 「게임 목록」 을 「병합」 으로 둬요. 「전체 교체」 로 보내면 그 실행 명령이 사라져 게임이 안 켜질 수 있어요.

기기 메타에 보태기

기기(USB)를 훑어 기기 롬과 팩 게임을 이은 뒤, 이어진 게임만 손봐요. 기기 목록에 줄이 있는 게임은 비어 있는 설명 · 인원 · 개발사 · 배급사 · 장르 · 출시일 · 평점만 채우고, 줄이 없는 게임은 끝에 새로 붙여요. 기기에 있던 실행 명령 · 제목 · 그림 경로는 건드리지 않고, 롬 · 그림 파일도 옮기지 않아요.

  • 「PC 에 저장」 은 결과를 폴더에 두기만 해요. 「기기에 넣기」 는 확인 창을 거쳐 기기 파일을 바로 바꾸고, 원본은 저장 폴더 아래 _backup 에 챙겨요.
  • 「이름이 비슷한 것도 잇기」 를 켜면 파일 이름이 조금 다른 것도 이어요. 이은 것은 표에 따로 보여요.

기기 설정 옮기기

머리줄 「기기 ▾ › 기기 설정…」 은 안드로이드 기기의 Pegasus · 에뮬레이터 설정 폴더를 팩 안 devices/ 에 저장해 두고 새 기기에 그대로 넣어요. 롬 · 그림은 이 창이 아니라 「내보내기」 가 보내요.

  • 기기가 안 보이면 USB 를 꽂고 기기 잠금을 푼 뒤 「파일 전송」 을 골라 「다시 찾기」 를 눌러요.
  • 캐시 · 로그는 빼고 저장해요. 같은 이름으로 다시 저장하면 고른 항목만 갈아끼워요.
  • 「묶음(zip) → 팩에 저장」 은 기기 없이 내부 저장소를 통째로 담은 zip 에서 저장해요.
조심「팩 → 기기에 넣기」 는 같은 이름 파일을 덮어쓰고 다른 파일은 지우지 않아요. 넣기 전에 기기의 지금 설정을 백업할지 물어요 — 「백업하고 넣기」 · 「백업 없이 넣기」 · 「그만두기」(Pegasus 설정은 늘 백업해요). 백업은 팩 devices/_backup/ 에 두고 저장본 목록에 「넣기 전 백업」 으로 나와요 — 그것을 골라 넣으면 되돌려요. 「백업 없이 넣기」 로 덮인 에뮬레이터 설정은 되돌릴 수 없어요.

설정·업데이트

머리줄 오른쪽 끝 톱니바퀴를 눌러요. 왼쪽 탭마다 따로 저장해요. 키와 비밀번호는 이 PC 안에서 Windows 가 주는 열쇠로 잠가 보관해요.

설정 창

계정
Create Pack 계정. 「사용자 그림」 을 올리거나 ♥ 를 누르려면 여기서 카카오 · 구글로 로그인해요(3장 사용자 그림). 팩 정리 · 스크래핑 · 한글패치는 로그인 없이 다 돼요.
ScreenScraper
본인 계정. 「계정 확인」 으로 오늘 남은 조회 수를 봐요.
AI 글 채우기 · 번역
Gemini · ChatGPT · Claude 중에 고르고 그 키를 넣어요. 「키 확인 · 모델 받기」 로 모델 목록을 받아요. 구독과 API 결제는 따로예요.
AI 미디어 한글화 · 편집
미디어 한글화와 AI 누끼 따기가 쓸 서비스(Gemini · OpenAI)와 이미지 모델. OpenAI 키는 ChatGPT 키와 같은 자리예요. 저장만으로는 아무 요청도 보내지 않아요.
단축키
메인 화면 · 메타 편집 창의 키를 바꿔요. 「바꾸기」 를 누르고 쓸 키를 누르면 바로 쓰여요(Esc 는 그만두기). 「모두 처음 키로」 로 되돌려요.
테마
크림 · 검정 · 회색 · 보라 · 오락실 다섯 가지. 고르면 바로 바뀌어요. 같은 탭의 「화면 크기」 는 「자동」 이면 창이 작을 때 화면을 줄여 더 많이 보여 주고, 글자가 흐려 보이면 80 ~ 110% 중에 정해 둬요.
업데이트 · 진단
「켤 때 새 판이 있는지 확인」 을 켜 두면 켤 때마다 봐요. 「지금 확인」 으로 바로 볼 수도 있어요. 「진단 정보 복사」 는 앱 판 · Windows 판과 최근 오류 기록을 복사해요 — 문의할 때 붙여 넣어요(홈 폴더 · 나스 이름 · 주소 속 계정은 가려져요).
업데이트

새 판이 있으면 「새 판이 나왔어요」 창이 떠요. 「바뀐 점 보기」 로 이 사이트의 업데이트 내역을 열 수 있어요.

「확인」 을 누르면 받아서 exe 를 갈아끼우고 다시 켜요. 받은 파일이 우리가 낸 것인지 서명으로 확인하고, 맞지 않으면 바꾸지 않아요. 옛 exe 는 같은 폴더에 .old 로 남았다가 다음에 켤 때 지워져요. 「취소」 는 이번만 넘기고 다음에 켤 때 또 물어요.

계정

「사용자 그림」(3장)에 그림을 올리거나 ♥ 를 누를 때만 필요한 Create Pack 계정이에요. 팩 정리 · 스크래핑 · 한글패치 · 내보내기는 로그인 없이 다 돼요.

  • 「카카오로 시작하기」 · 「구글로 시작하기」 를 누르면 브라우저에서 로그인하고, 끝나면 앱의 창이 저절로 닫혀요. 처음이면 가입 동의 창이 떠서 넷(만 14세 · 이용약관 · 개인정보 처리방침 · 올리는 그림의 권리)에 모두 동의해야 가입돼요. 따로 된 비밀번호는 없어요.
  • 앱이 받는 것은 카카오 · 구글의 회원 번호뿐이에요. 이메일 · 실명 · 프로필 사진은 받지 않아요.
  • 로그인 뒤 「별명 정하기」 로 별명을 정해요(완성된 한글 · 영문 · 숫자 2~12자 · 다른 사람과 겹치면 안 돼요). 그림을 올리거나 ♥ 를 누르려면 별명이 있어야 해요.
  • 왼쪽 카드에 올린 그림 · 받은 ♥ · 적용 수 · 이번 달 순위가 보여요. 「순위에 안 나오기」 를 켜면 순위 판에서 빠지고 그림의 별명은 그대로 보여요. 오른쪽 「내가 올린 것」 표에서 상태(공개됨 · 확인 중 · 숨겨짐 · 내려짐 · 거절됨)를 보고 지워요.
  • 「로그아웃」 은 이 PC 에서만 풀려요. 「탈퇴…」 는 계정과 내가 누른 ♥ 를 지워요. 올린 그림은 남고 별명이 「탈퇴한 사람」 으로 바뀌며 그 그림의 ♥ · 적용 수는 0 이 돼요 — 지울 그림은 탈퇴 전에 지워 주세요. 탈퇴하면 3일 동안 다시 가입할 수 없어요.

되돌리기 어려운 것

대부분의 지우기는 팩 휴지통(_trash/)이나 PC 휴지통으로 가서 되살릴 수 있어요. 아래는 그렇지 않은 것들이에요.

계정 · 키 · 요금

  • ScreenScraper 는 무료 계정이고, 계정마다 하루 조회 수가 정해져 있어요.
  • AI 기능(글 채우기 · 번역 · 미디어 한글화 · 누끼 따기)은 본인 키로 각 서비스에 요청해요. 요금은 그 서비스에 나가고, ChatGPT · Gemini 구독과는 따로예요.
  • 키는 이 PC 안에만 보관하고 그 서비스에 요청할 때만 써요. 이 사이트에는 모이지 않아요.
  • Create Pack 계정(카카오 · 구글 로그인)은 「사용자 그림」 에만 쓰고 무료예요. 받는 것은 그 서비스의 회원 번호뿐이에요.

들어 있지 않은 것

Create Pack 에는 게임 파일 · BIOS · 열쇠가 들어 있지 않아요. 직접 가진 파일을 정리하는 도구예요. 한글패치도 목록과 정리만 도와요 — 패치는 배포처에서 직접 받아요.
