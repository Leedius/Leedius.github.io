업데이트 내역

판마다 바뀐 점이에요. 새 판이 나오면 맨 위에 더해요. 내려받기 단추는 늘 가장 새 판을 받아요.

Windows 용 내려받기

  1. 0.4.1

    2026-10-13

    한글패치 받기를 고친 판이에요.

    한글패치

    • 「받는 중」 일 때 같은 파일을 두 번째로 받으면 묻지도 옮기지도 않던 것을 고쳤어요. 롬이든 패치든 받을 때마다 어디에 넣을지 물어요.
    • 「멈추기」 는 받기만 꺼요. 전에는 옮긴 파일이 있을 때만 「패치 적용」 탭으로 넘어가서 넘어갈 때도 있고 안 넘어갈 때도 있었어요.

  2. 0.4.0

    2026-10-13

    UPS 한글패치도 앱에서 바로 걸 수 있는 판이에요.

    한글패치

    • 「패치 적용」 이 UPS(.ups) 패치도 걸어요. 원본 롬의 크기와 CRC 가 패치와 다르면 걸지 않아요.

  3. 0.3.0

    2026-10-12

    「패치 적용」 탭에서 게임 폴더 파일을 바로 정리할 수 있는 판이에요.

    한글패치

    • 「패치 적용」 탭에서 고른 원본 롬을 PC 휴지통으로 보낼 수 있어요. cue 면 트랙 파일까지, 여러 장이면 디스크 모두 보내요.
    • 「패치 적용」 탭 아래 빈 자리에 그 게임 폴더와 원본 폴더의 파일이 떠요. 줄마다 이름을 바꾸거나 PC 휴지통으로 보낼 수 있어요.
    • 한글패치 목록 표의 「롬 목록」 칸(다른 롬 관리 툴의 목록 DB 에 그 게임이 있는지 보던 칸)을 뺐어요.

  4. 0.2.0

    2026-10-12

    한글패치 목록 API · 패키지 한글화(AI) · 진행 창이 들어간 판이에요.

    한글패치

    • 한글패치 목록을 레트로디비(retrodb.info) 목록 API 로 받아요. 사이트에서 받은 내 키를 설정 창 「한글패치 목록 API」 에 넣고 한글패치 창의 「목록 받기」 를 누르면 새로 오른 패치와 새 판만 더해요. 가진 목록 · 「보유」 · 받은 기록은 그대로 둬요. 브라우저 콘솔에 붙여 넣던 스니펫은 없앴어요.
    • 처음 쓰는 사람도 지금까지 모인 한글패치 목록을 들고 시작해요. 키를 넣기 전에도 목록을 볼 수 있고, 「목록 받기」 를 누르면 그 뒤에 오른 것만 더해요.
    • 「받는 중」 을 누르면 게임 폴더와 원본 폴더를 같이 만들어요. 브라우저로 받은 파일마다 원본에 넣을지 게임 폴더에 넣을지 묻고, 원본에 넣은 zip · 7z 는 풀어 넣은 뒤 압축 파일을 지워요.
    • 「패치 적용」 탭에서도 받기를 멈출 수 있어요. 한글패치 창을 다시 열면 마지막에 고른 기종이 골라져 있어요.
    • 「패치 적용」 탭에서 게임을 고르면 원본과 패치의 해시를 스스로 계산해, 패치가 바라는 원본인지(✓ 맞음 · ✗ 틀림 · ? 미심쩍음) 표로 보여 줘요. bps 패치에 든 값과 함께 받은 설명 글(checksums.txt · readme 등)에 적힌 해시로 견줘요.
    • 검사 값이 없는 xdelta 패치는 설명 글에 적힌 결과 해시로 제대로 걸렸는지 확인해요.
    • 원본으로 zip · 7z 압축 파일을 골라도 안의 롬을 풀어 패치를 걸어요.
    • CD 이미지 원본이 오류 정정 값(EDC · ECC)만 달라 패치가 안 걸리면, 그 값을 다시 계산한 사본에 한 번 더 걸어요.
    • 드림캐스트 DCP 한글패치를 GDI 원본의 사본에 걸어요. 결과를 압축하면 트랙 파일도 휴지통으로 치워요.
    • 3DS cia 를 풀어 다시 묶은 것을 기준으로 만든 패치도 내 cia 원본에 걸어요. 필요하면 cia 를 롬(.3ds)으로 바꿔 걸어요.
    • 한글패치 창에서 롬을 여럿 골라 기종에 맞는 꼴로 한꺼번에 압축해요.
    • 「롬 압축…」 이 없는 트랙 파일을 가리키는 cue 를 옆에 있는 같은 이름의 bin · img 로 고쳐 써요. 트랙이 여럿이어도 돼요.
    • 한글패치를 건 뒤 압축 같은 다음 단계에서 멈추면, 패치는 걸렸다는 것과 어느 단계에서 멈췄는지 알려 줘요.
    • 기종 폴더 바로 아래에 롬 파일이 있으면 「보유」 칸을 못 읽던 것을 고쳤어요.

    패키지 한글화(AI)

    • 게임 편집 창의 「패키지 한글화(AI)…」 로 표지 · 옆면 · 로고 · 3D 박스 · 박스 전개 · 스크린샷 · 타이틀 · 카트리지 그림 속 글자를 한글로 바꾼 그림을 만들어요. 원본과 결과를 한 화면에서 확대해 견주고, 고른 결과만 저장해요.
    • 바꾸기 전에 글자 확인 창에서 바꿀 글자를 보고 고칠 수 있고, 결과 확인 창에서 결과 그림의 글자를 다시 읽어 보여 줘요. 박스 전개를 고르면 표지 · 옆면 · 3D 박스를 잘라 만들어요.
    • 종류마다 AI 적용 전 그림으로 되돌릴 수 있고, 실패한 그림만 다시 시도할 수 있어요.
    • 설정 「패키지 한글화(AI)」 에서 Gemini 와 OpenAI 중 고르고 이미지 모델을 골라요. OpenAI 키는 Gemini 키와 따로 넣어요. 내 키로 각 서비스에 요청하니 요금은 그 서비스에 나가요.

    내보내기

    • 내보내기 창을 「무엇을」 과 「어디로」 두 줄로 나눴어요. 보던 시스템만 체크된 채 열리고, 창 아래에 무엇을 어디로 보내는지 한 줄로 보여 줘요.
    • 「크기가 같아도 다시 보내기」 를 더했어요. 크기는 같고 내용만 바뀐 롬도 다시 보낼 수 있어요. 끈 채 건너뛴 것이 있으면 결과 글이 알려 줘요.
    • 롬을 다 보낸 뒤에 게임 목록 파일을 써요. 도중에 멈추면 목록은 그대로 두고, 팩에 없어 못 보낸 롬은 진행 창에 이름을 남겨요.
    • 폴더 이름에 상위 경로나 경로 구분자가 들어가면 전송 전에 막아 선택한 목적지 밖으로 나가지 않아요.
    • 내보낼 기종의 출력 폴더나 파일 경로가 겹치면 알려 줘요. 폴더 이름을 고치거나 해당 기종의 체크를 풀면 진행할 수 있어요.

    팩 · 편집 · 화면

    • 오래 걸리는 작업(내보내기 · 압축 · 한글패치 적용 · 롬 복사 · 게임 넣기 · 기기에서 받기 · 기기 설정 · 일괄 스크래핑)은 따로 뜬 진행 창에서 지금 파일 · 퍼센트 · 옮긴 크기를 보여 줘요. 멈출 수 있는 작업은 그 창에서도 멈춰요.
    • 팩이 열려 있지 않으면 「팩 열기…」·「새 팩 만들기…」 카드를 보여 주고, 팩이 있어야 하는 단추는 잠가요. 「기기 설정…」 도 팩을 연 뒤에 쓸 수 있어요.
    • 시스템을 골라도 시스템 목록이 저절로 접히지 않아요. 접기는 단추로만 하고, 접은 채 두면 다음에 켤 때도 접혀 있어요. 제목이 없는 게임은 제목 자리에 파일 이름을 흐리게 보여 줘요.
    • 「시스템 다시 맞추기」 의 이름을 「롬 폴더 다시 읽기」 로 바꿨어요. 메뉴와 방식에 마우스를 올리면 예를 보여 줘요.
    • 게임 편집 창에서 바꾼 것을 「적용」 하지 않고 닫으면 저장할지 물어요. 그림 떼기 · 교체 · 편집은 바로 저장된다고 창에 적어 두었어요.
    • 그림 편집에서 바꾼 내용을 적용하지 않고 Escape나 취소로 닫으면, 계속 편집할지 버리고 닫을지 물어요.
    • 그림 편집에서 조각을 얹은 채 「적용」 을 눌러도 조각까지 같이 저장해요. 크기조절 단추 이름은 「크기조절 실행」 으로 바꿨어요.
    • AI로 채우기에서 「AI 에게 묻기」 를 다시 누르면 앞서 받은 값은 그대로 두고, 못 받은 칸이 남은 게임만 다시 물어요.
    • 게임 검색이 영어 제목과 파일 이름으로도 찾아요.
    • 체크한 게임이 검색에 가려져 있으면 상태 줄에 알려 주고, 「선택 풀기」 로 한꺼번에 풀 수 있어요. 휴지통으로 옮길 때는 확인 창에 어떤 게임인지 보여 줘요.
    • 시스템을 가져올 때 Android나 SFTP로 바꿨다가 내 컴퓨터로 돌아와도, 고른 폴더의 메타데이터 선택을 유지해 원본 제목을 함께 가져와요.
    • 창을 더 좁게 줄일 수 있어요(1280 너비 화면의 노트북에 맞게).

    고친 것

    • 휴지통에서 되돌릴 때 팩에 같은 이름의 롬 · 그림이 이미 있으면 덮지 않아요. 롬이 있으면 되돌리지 않고, 그림만 있으면 팩에 있는 그림을 둬요.
    • 게임 편집 창에서 찾기 · AI 채우기의 답을 기다리는 사이 다른 게임을 열면, 앞 게임의 답이 새 게임 칸에 들어가던 것을 고쳤어요.
    • 게임 넣기 복사가 도중에 막히면 반쯤 복사된 파일도 치워요.
    • 기기에서 시스템을 가져올 때 팩에 이미 있는 시스템이면 받기 전에 멈춰요. 전에는 받으면서 있던 롬 폴더를 덮을 수 있었어요.
    • 화면 새로고침이 실패하면 그 까닭을 알려 줘요. 전에는 아무 일 없던 것처럼 보였어요.
